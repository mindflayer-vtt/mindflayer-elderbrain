# Third-party components

The appliance uses Ubuntu Server, Docker Engine/Compose, Traefik, Sway/wlroots, Google Chrome, `felddy/foundryvtt`, and `mindflayer-vtt/mindflayer-server`. Their licenses and release notices remain authoritative. Foundry VTT is proprietary and is downloaded only after its owner supplies an officially supported credential or timed URL; this repository and its ISO redistribute no Foundry binary, license, or credential.
